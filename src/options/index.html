Auto Pricing

Project-approved automated shop price lookup and application with mandatory review.

Explicit opt-in and project-specific approval

Auto Pricing is off by default. The repository owner states that this project has approval to use this feature and the official daily item icons. That statement is not a general authorization for other users or deployments.

Permit price scans and reviewed shop price updates on your own shop stock page.

Scan, calculate, and review without submitting any price changes.

Verified once, never blindly retried

Each run is rate limited. Real updates require a fresh copy of shop stock, exact-plan confirmation, and a cross-tab lock. The extension submits once, fetches the shop again, and reports success only after every selected price matches.

Auto Buy

A guarded one-item workflow for an explicitly selected Shop Wizard result.

Off by default, dry-run by default

A real run can spend Neopoints. It is limited to one item, requires an explicit review, rechecks the exact listing, blocks duplicates, and never retries an uncertain result.

Permit a reviewed one-item workflow on Shop Wizard results pages.

Validate and review a listing without following its purchase URL.

Exact listing, quantity one, no blind retry

Item name, owner, object ID, visible price, purchase URL, and price ceiling must all match. Uncertain results are retained for duplicate protection and require manual inventory inspection.

Privacy & Data

Understand, export, import, or remove the data stored by the extension.

Stored locally

Settings, custom routines, completion history, and redacted operation status are stored in Chrome extension storage on this device.

Transmitted only to Neopets

When Auto Pricing or Auto Buy runs, validated item details and approved operations are sent only to fixed HTTPS endpoints on www.neopets.com using your existing signed-in browser session.

No telemetry

No analytics, advertising, developer server, tracking SDK, or remote executable code is included.
